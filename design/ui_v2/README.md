# UI v2

Put the v2 design files here — mockups, exported screens, flow diagrams,
whatever form they are in (PNG / JPG / PDF / Figma export).

Naming that helps: one file per screen, prefixed by the screen it replaces, e.g.

    home_v2.png
    hearing_user_v2.png
    deaf_mute_v2.png
    signal_modal_v2.png

Kept outside flutter_app/ deliberately: anything under flutter_app/assets/ is
bundled into the APK, and design sources should not ship to users.
